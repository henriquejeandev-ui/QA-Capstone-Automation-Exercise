## Objective

Validate the core functionalities of the Automation Exercise e-commerce 
platform — user authentication, account registration, product search, 
cart management, and checkout — covering success, failure, and 
required-field scenarios.

## Scope

**In Scope:**
- User authentication (login) via form
- New account registration, including required field validation
- Product search (existing and non-existing products)
- Cart management (add, remove, change quantity)
- Checkout flow (successful purchase and cancellation)

**Out of Scope:**
- Payment data validation (the site does not process real payments)
- Performance/load testing
- Security testing
